THE AI ECOSYSTEM COMPASS FOR EDUCATORS

Open AI-Ecosystem-Compass.html in a browser. All graphics, styling and interactions are included in this one file.

IPAD
The layout adapts to portrait and landscape. Local Files previews may not run JavaScript; use an HTML viewer, or use Safari after publishing the file as a website. Browser checks covered 768px and 1024px tablet layouts and 390px mobile layouts. Physical iPad/Safari testing remains to be done.

GITHUB PAGES
When ready to publish, upload a copy named index.html into the folder used by your GitHub Pages site. No build, package installation or supporting assets are needed. This task has not published the website.

WORKSHOP
The eight agreed sections, six belief spectrums and Five Tribes names are preserved from the referenced conversation. Graphics and detailed supporting prompts were recreated from the available conversation; the original canvas source was not available.

Answers save in the current browser when permitted. Export before clearing browser data or moving devices. The full reflection export contains notes in readable JSON. The print option produces a printable workshop with current answers; the scenario section prints the currently selected scenario. Other scenario notes remain in the full reflection export.

GROUP DASHBOARD
Participants use Export my ratings for sharing. The facilitator imports the JSON files. The dashboard merges records by response ID, so importing an updated file replaces the previous ratings. Imports accept ratings only; private reflection notes are never added to the group dashboard. There is no live multi-device synchronisation. Start a new personal response when passing one device to another participant, after exporting the previous response.

DATA
No network requests, analytics, sign-in or external dependencies. Responses remain on the device unless exported and shared. Full reflection JSON is an archive; importing it adds its ratings to the dashboard and does not restore its private notes to the form.
